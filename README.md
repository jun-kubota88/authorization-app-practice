## 概要
COACHTECH 教材 Tutorial 10-3「認可機能 ハンズオン演習」で作成した成果物です。

## 使用技術
- PHP 8.x
- Laravel 10.x
- Policy / Gate（認可）
- Laravel Fortify（認証）

## 学んだこと
- 認証（誰か）と認可（何ができるか）の違いと使い分け
- Policy クラスでモデルに紐づく認可ロジックを定義する仕組み
- Blade の @can ディレクティブとコントローラの $this->authorize()
